Sin estos mecanismos de sincronización, un hilo podría sobrescribir un valor antes de que el otro lo leyera, provocando que algunos datos se pierdan. Con wait() el hilo queda bloqueado hasta que puede continuar su ejecución, mientras que con notifyAll() se avisa al resto de hilos de que pueden seguir trabajando. De esta forma se consigue una comunicación correcta entre el hilo que establece los valores y el hilo que los obtiene y se garantiza que todos los valores generados sean leídos correctamente.
